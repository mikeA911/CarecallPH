On **Clinicians**, use **Add clinician** (name and optional specialty). Select a
clinician to edit their **Weekly availability**: for each weekday, **+ add** a
time range; **×** deletes one. Clinicians can be made inactive.

Bookable slots come only from this availability, minus existing appointments,
split by the campaign's slot length. If a campaign offers few or no times,
check availability here first.
