## Steps

1. Ask the platform admin to enable **chat invites** (and optionally
   **self-booking**) for the clinic. There is no toggle in the portal yet;
   CC can file an action item for this.
2. Make sure patients have **sms_consent** set: invites travel in the
   pre-call or voicemail text message.
3. Turn on the **Pre-call text message** in Clinic settings.
4. At the front desk, tell patients they'll get a link to receive reminders on
   Viber (or Messenger, WhatsApp, Telegram) and should reply YES in the chat.
5. After a campaign round, ask CC how many messages went out per channel.

A printable front-desk QR code is planned but not available yet.
